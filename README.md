# Lumina Luxe

Build a premium ecommerce site for an Australian fine jewellery brand, inspired by the energy and layered animated hero experience of https://drinkjoyrush.com/ but with an original jewellery-focused design. Make it feel exceptional and editorial: bright light theme only, no gradients, no dark mode, no sloppy/generic UI, and explicitly avoid Indian/Asian jewellery motifs or styling. Create an out-of-this-world layered animated hero using refined product imagery/placeholders, elegant motion, depth, and high-end typography. Include responsive mobile and iPad layouts. Build shop/category views, sophisticated product detail pages with image gallery, product specs, variants, add-to-cart, cart drawer/page, and a clear checkout experience. User only uses Stripe: enable Lovable Cloud as needed for ecommerce state, and implement Stripe payment flow; ask for Stripe connection/key only when needed. Use Australian brand voice, AUD pricing, and create a coherent collection of contemporary fine jewellery products.
